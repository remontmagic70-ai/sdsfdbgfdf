# Магия Ремонта плюс

Демо калькулятора ремонта квартир для компании «Магия ремонта», Томск. Смета по пакетам и этапам, живая 3D-квартира.

Статический сайт без сборки. Публикуется на Vercel из ветки main, каждый пуш обновляет сайт.

Заявки пока в демо-режиме: форма показывает экран отправки, но данные никуда не уходят.
